## 范围与标准

- 新增案例不含原220（及附录候选6条）；以中英名、设计方、地点、年份、来源URL交叉去重，含同项目异名。
- 优先精致现代小尺度：微空间、口袋公园、小院、层次丰富的植物庭院、轻薄开敞亭子；类型可适度扩展，但不以候选链接凑数。
- 每条打开原项目页核验，不用搜索摘要代替原文。基础字段按来源原有表述，缺值写“来源未列”。事实要点中性、短句、逐条给来源，不写自创营销评价，不整篇复制版权文章。
- 图片以原图下载为准，经Content-Type与PIL校验、哈希去重；不渲染、不施工前图充数；每项目目标6–10张（最多10），不足6张如实标明；至少3张建成实景。图不压缩、不改绘。
- 总manifest只计完整合格项目。候选另放，不计入500。
